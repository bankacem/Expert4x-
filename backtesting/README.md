# نظام الاختبار الخلفي للمتداول الآلي (Forex Hacked Pro Backtester)

## 📋 وصف النظام

نظام شامل لاختبار وتحسين المتداول الآلي "Forex Hacked Pro" على بيانات حقيقية من سنة كاملة.

## 🎯 المميزات

✅ **جلب البيانات الحقيقية**: تحميل بيانات فوركس حقيقية بفاصل ساعي (H1) لسنة كاملة

✅ **محاكاة دقيقة**: محاكاة استراتيجية Martingale مع ثلاث مؤشرات رئيسية:
   - RSI (Relative Strength Index)
   - MACD (Moving Average Convergence Divergence)
   - Bollinger Bands

✅ **إدارة المخاطر**: تتبع التراجع القصوى (Drawdown) والرصيد

✅ **تحسين الإعدادات**: اختبار مئات المجموعات للعثور على الأفضل

✅ **تقارير مفصلة**: نتائج شاملة لكل اختبار مع إحصائيات مفصلة

## 🚀 البدء السريع

### 1. التثبيت

```bash
cd backtesting
pip install -r requirements.txt
```

### 2. تحميل البيانات

```bash
python forex_data_downloader.py
```

سيقوم بـ:
- تحميل بيانات 9 أزواج عملات
- تحديد فترة سنة كاملة
- حفظ البيانات في مجلد `forex_data`

### 3. اختبار المتداول

```bash
python martingale_backtester.py
```

سيختبر المتداول على EURUSD ويعطيك:
- إجمالي الربح/الخسارة
- معدل الفوز
- أقصى تراجع
- عينة من العمليات

### 4. تحسين الإعدادات

```bash
python optimizer.py
```

سيقوم بـ:
- اختبار عشرات المجموعات المختلفة
- إيجاد أفضل الإعدادات
- إظهار أفضل 5 نتائج
- حفظ التوصيات النهائية

## 🔧 الإعدادات المتاحة

### إعدادات المتداول (في `martingale_backtester.py`)

```python
settings = {
    'initial_balance': 1000,        # الرصيد الأولي ($)
    'lot_size': 0.1,               # حجم اللوت
    'martingale_multiplier': 2,    # مضاعف Martingale
    'tp_pips': 50,                 # Take Profit (نقطة)
    'sl_pips': 100,                # Stop Loss (نقطة)
    'max_dd_percent': 30,          # أقصى تراجع مسموح (%)
    'rsi_overbought': 70,          # مستوى RSI العلوي
    'rsi_oversold': 30,            # مستوى RSI السفلي
    'use_martingale': True         # استخدام Martingale
}
```

## 🎓 الإحصائيات المهمة

### معدل الفوز (Win Rate)
- **الحد الأدنى المقبول**: 50%
- **الحد الجيد**: 55-60%
- **الممتاز**: أكثر من 65%

### التراجع القصوى (Max Drawdown)
- **منخفض المخاطرة**: < 15%
- **متوسط المخاطرة**: 15-25%
- **عالي المخاطرة**: > 30%

### العائد على الاستثمار (ROI)
- **تحذير**: ROI < 5% قد يشير لضعف الاستراتيجية
- **جيد**: ROI بين 10-20%
- **ممتاز**: ROI أكثر من 20%

## ⚠️ تحذيرات مهمة

1. **Martingale خطير**: الاستراتيجية تستخدم Martingale التي قد تؤدي لخسائر كبيرة

2. **البيانات التاريخية**: الاختبار على البيانات السابقة لا يضمن النتائج المستقبلية

3. **Slippage والرسوم**: لم تُأخذ بعين الاعتبار تكاليف السبريد والرسوم الفعلية

4. **اختبار على Demo أولاً**: اختبر على حساب تجريبي قبل استخدام أموال حقيقية

5. **المراقبة المستمرة**: راقب الأداء باستمرار وكن مستعداً لإيقاف المتداول
